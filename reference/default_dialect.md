# CSVW default dialect

The [CSVW Default Dialect
specification](https://w3c.github.io/csvw/metadata/#dialect-descriptions)
described in [CSV Dialect Description
Format](http://dataprotocols.org/csv-dialect/).

## Usage

``` r
default_dialect
```

## Format

An object of class `list` of length 13.

## Value

a list specifying a default csv dialect
