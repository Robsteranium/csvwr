# csvwr: Read and write CSV on the Web (CSVW)

Read and write csv tables annotated with [csvw
metadata](https://w3c.github.io/csvw/metadata/). This helps to ensure
consistent processing and reduce the amount of manual work needed to
parse and prepare data before it can be used in analysis.

## Getting started

The best place to start is the [Reading and Writing
CSVW](https://robsteranium.github.io/csvwr/doc/read-write-csvw.md)
vignette.

## Reading annotated tables

- [`read_csvw`](https://robsteranium.github.io/csvwr/reference/read_csvw.md)
  Parse a table group

- [`read_csvw_dataframe`](https://robsteranium.github.io/csvwr/reference/read_csvw_dataframe.md)
  Parse a table group and extract the first data frame

## Writing table annotations

- [`derive_table_schema`](https://robsteranium.github.io/csvwr/reference/derive_table_schema.md)
  Derive table schema from a data frame

- [`create_metadata`](https://robsteranium.github.io/csvwr/reference/create_metadata.md)
  Create a table group annotation

- [`derive_metadata`](https://robsteranium.github.io/csvwr/reference/derive_metadata.md)
  Derive an annotation from a csv file
