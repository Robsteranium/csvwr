# Compact objects to values

Follows the [rules for JSON-LD to JSON conversion set out in the
csv2json
standard](https://w3c.github.io/csvw/csv2json/#json-ld-to-json).

## Usage

``` r
compact_json_ld(value)
```

## Arguments

- value:

  an element from a list (could be a vector or another list)

## Value

A compacted value.
