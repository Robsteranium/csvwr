# Convert a csvw metadata to a list (csv2json)

Convert a csvw metadata to a list (csv2json)

## Usage

``` r
csvw_to_list(csvw)
```

## Arguments

- csvw:

  a csvw metadata list

## Value

a list following the csv2json translation rules

## Examples

``` r
if (FALSE) { # \dontrun{
csvw_to_list(read_csvw("example.csv"))
} # }
```
